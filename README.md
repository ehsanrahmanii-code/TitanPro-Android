# TITAN Pro V80 — Android (Chaquopy)

اپ اندروید کامل و **خودکفا** با موتور TITAN Pro V80 داخل APK (Chaquopy).

**دانلود کامل پروژه (ZIP با همه فایل‌ها از جمله titan_pro_all.py):** در بخش Releases یا از همین ریپو بعد از کامل شدن آپلود.

## لینک ریپو
https://github.com/ehsanrahmanii-code/TitanPro-Android

## ساخت APK
1. کلون کنید: `git clone https://github.com/ehsanrahmanii-code/TitanPro-Android.git`
2. با Android Studio باز کنید (JDK 17)
3. `./gradlew assembleDebug`
4. APK در `app/build/outputs/apk/debug/`

## مهم
- فایل `app/src/main/python/titan_pro_all.py` (حدود ۲ مگابایت) باید در جای خودش باشد.
- مجوز All-files access روی گوشی الزامی است.
- فقط analysis-only — بدون سفارش واقعی.
